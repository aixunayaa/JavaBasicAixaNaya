# 🧠 Java Básico – Aixa Naya

Este repositorio contiene una colección de ejercicios básicos de Java, realizados con fines educativos. 
Los ejercicios cubren distintos temas fundamentales del lenguaje y están organizados en distintas carpetas por actividad o práctica.

---

## 📚 Temas abordados

Los ejercicios incluyen:

- Declaración y uso de variables
- Operadores aritméticos y lógicos
- Control de flujo (`if`, `else`, `switch`)
- Bucles (`for`, `while`)
- Entrada por teclado con `Scanner`
- Lógica básica en Java
